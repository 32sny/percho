## 三、冲突与待讨论决策

2026-11-15用户已确认句中引用/Lexical的提前规划，排序已回写catalog；P3–P8编号不变。其余行仍是推荐默认项，不表示用户已选择。本次只批准规划调整。

| 决策 | 选项 | 推荐及原因 |
| --- | --- | --- |
| 句中引用时机（已定） | 采用B：从P8提前到P2内独立迁移批次 | 模型提取A1–A3之后，先保持textarea行为完成输入层解耦，再接Lexical与句中引用；不与其他大改并行，不建立长期双编辑器；尚未实施 |
| 长消息折叠默认 | A 长消息默认收起；B 默认展开、用户手动折叠；C 记住用户偏好 | 推荐C，既减少长会话占用，又不强迫改变阅读习惯 |
| 归档含待发送项 | A 忙碌或有未确认输入时拒绝；B 显式停止/处置后再归档；C 静默丢弃再归档 | 推荐A作为首版，后续B另设确认；C不可接受 |
| 截图整理恢复 | A 暂缓；B 用户手动预览收益、备份后执行；C 默认后台自动处理 | 推荐B作为单独规划，收益不足时A；不采用C默认改历史 |
| 权限变化 | A 保留现策略仅优化UI；B 增加可选模式并说明范围；C 跟随截图自动开启宽松模式 | 首批A；B需独立需求。不能因视频显示auto采用C |
| 数据迁移引导 | A 跟随P8独立迁移；B 与普通UI同步一起迁移 | 推荐A。已有“跟随独立目录”方向保留，迁移前演练与回退仍需独立设计 |

模型发现不必等待整个P2全部完成；可作为P2内的独立候选。Windows `WIN-LINK-01`仍是独立缺陷，先恢复系统打开，应用内安全预览归P4，不被模型发现替代。

## 六、后续验收设计

本轮没有实现或测试通过声明。未来按功能取最窄测试与UI场景：

- 结构化引用位于句中，发送/恢复后顺序一致，图片/附件/斜杠命令与三模式不回归。
- 历史分页与小地图在大数据夹具下对同一消息定位；加载失败/取消/切会话不串数据，不用伪滚动占位冒实际历史。
- 子代理只读不可发送，回父定位身份正确；并行失败/取消/queued状态和插件兼容有证据。
- 统计来源真实、定义明确；无usage显示未知而不是0速度。
- 归档与恢复不丢pending，清理期间拒绝并发写；媒体整理有原始备份/校验和中断恢复，不能因文件变小宣称无损。
- 迁移演练使用隔离副本，旧目录不删；重复运行、磁盘不足、异常退出可判定。
- UI按docs/ui.md，图片预览/权限控件在真实Windows验证；截图是设计参考，不是验收结果。
